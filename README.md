# Getting Better

A universal quality protocol for Claude — applies to coding, writing, 
design, analysis, planning, and research.

## What it does
- Batches 5–10 clarifying questions with sensible defaults before 
  starting substantial work, instead of trickling questions one at a time
- Produces dense, no-padding output — no hedges, no restated context
- Carries corrections forward as standing rules for the rest of the 
  session, so you never have to repeat a fix

## When it triggers
Any task involving building, writing, coding, designing, analyzing, 
or planning — especially short or open-ended requests. Skips 
lightweight Q&A and casual exchanges.

## Constraints
- Question batch is capped at 10 — no open-ended interrogation
- Defaults must be stated, not just implied, if the user doesn't answer
- Never re-asks something already answered or corrected earlier in 
  the same session
- Scales down for trivial tasks — a one-line fix doesn't need five 
  clarifying questions
- Output favors substance over structure — no filler headers, no 
  repeated summaries
